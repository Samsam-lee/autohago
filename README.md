# 국가법령정보 조회 (Claude용 법령 원문 조회 도구)

Claude에게 세법 질문을 하면 Claude가 **법제처 국가법령정보에서 현행 법령 원문을 직접 조회한 뒤**, 그 원문을 근거로 답하게 해 주는 도구입니다.

---

## 1. 왜 이걸 쓰나요?

Claude는 원래 학습한 지식으로 답합니다. 그런데 세법은 해마다 개정되기 때문에 그대로 쓰면 이런 문제가 생깁니다.

| 문제 | 예시 |
|---|---|
| 개정 전 내용으로 답함 | 비과세 한도나 공제 금액이 예전 기준으로 나옴 |
| 조문 번호를 잘못 말함 | 실제와 다른 조·항·호를 근거로 듦 |
| 시행령을 확인하지 않음 | 법률에 "대통령령으로 정하는"이라고만 되어 있는 세부 요건을 추측함 |
| 근거를 확인할 수 없음 | 답이 맞는지 원문과 대조하기 어려움 |

이 도구를 설치하면 Claude가 답하기 전에 법제처에서 **현행 원문을 직접 조회**하고, 답변에 **근거 조문과 시행일**을 함께 적습니다. 그래서 답이 맞는지 바로 원문과 대조할 수 있습니다.

> 이 도구는 법령 원문 확인을 돕는 보조 도구입니다. 예규·판례·유권해석은 조회하지 않으며, 최종 판단은 담당자가 직접 검토해야 합니다.

---

## 2. 구성

| 파일 | 용도 |
|---|---|
| `dist/korean-law.mcpb` | **이 파일 하나만 설치하면 됩니다.** 법령 조회 도구와 답변 규칙("세법 질문에는 원문을 조회하고 근거 조문과 시행일을 밝혀 답하라")이 함께 들어 있습니다. |
| `dist/korean-tax-law-skill.zip` | 선택 사항. 같은 답변 규칙을 Skill로 만든 파일입니다. 확장만 설치했는데 Claude가 답변 형식을 잘 지키지 않을 때만 추가로 등록합니다. |

> **플러그인(Plugin)으로 등록하지 마세요.** 플러그인에 들어간 로컬 도구는 일반 채팅에서 동작하지 않습니다. 반드시 아래 3단계의 **확장 프로그램**으로 설치합니다.

Claude가 쓰는 도구는 세 가지입니다.

- **법령 검색**: 법령명으로 법률·시행령·시행규칙을 찾습니다.
- **조문 조회**: 조문 원문을 항·호·목까지 가져옵니다. 제12조의2 같은 가지조문도 됩니다.
- **키워드 검색**: 조 번호를 몰라도 "식사대" 같은 단어로 조문을 찾습니다.

## 3. 설치 방법 (직원용, 무료 플랜 가능)

처음 한 번만 하면 됩니다. 약 15분 걸리고, 1단계는 승인까지 하루 정도 걸릴 수 있습니다.

### 1단계. 법제처 OC 발급받기

OC는 법제처 Open API를 쓰기 위한 개인 아이디입니다. **각자 본인 것을 발급받아 주세요.**

1. [open.law.go.kr](https://open.law.go.kr)에 회원가입합니다.
2. 로그인한 뒤 **OPEN API 사용 신청**을 합니다.
   - 사용할 API: **법령**을 선택합니다. 법령 본문 조회도 함께 선택합니다.
   - 서버 IP: **사무실 공인 IP**를 적습니다. 네이버나 구글에서 "내 IP"를 검색하면 나오는 숫자입니다.
3. 승인될 때까지 기다립니다. 바로 되거나 하루 정도 걸립니다.
4. **내 OC 값 = 가입한 이메일의 @ 앞부분**입니다.
   - 예: `abc123@naver.com`으로 가입했다면 OC는 `abc123`입니다.

### 2단계. Claude 데스크톱 앱 설치

1. [claude.com/download](https://claude.com/download)에서 Windows용 Claude 데스크톱 앱을 설치합니다.
2. 본인 Claude 계정으로 로그인합니다. 무료 계정도 됩니다.

> 웹 브라우저(claude.ai)가 아니라 **데스크톱 앱**이어야 합니다. 확장 파일은 데스크톱 앱에서만 설치됩니다.

### 3단계. 확장 파일 설치

1. `korean-law.mcpb` 파일을 받아 둡니다.
2. Claude 데스크톱 앱에서 **설정 → 데스크톱 앱(Desktop app)**으로 들어갑니다.
3. **확장 프로그램(Extensions)** 옆의 **관리(Manage)**를 누릅니다.
   - 예전 버전 앱은 설정 목록에 **확장 프로그램(Extensions)**이 바로 있습니다.
4. 열린 화면에 `korean-law.mcpb` 파일을 **끌어다 놓습니다.**
   - 안 되면 **고급 설정(Advanced settings) → 확장 프로그램 설치(Install Extension…)**에서 파일을 선택합니다.
5. 미리보기 화면에서 **설치**를 누르고, **"법제처 Open API 인증키 (OC)"** 칸에 1단계의 OC 값을 입력합니다.
6. 목록에 **국가법령정보 조회**가 보이는지, **켜져 있는지** 확인합니다. 설치 직후 꺼져 있을 수 있습니다.

> "서명되지 않은 확장"이라는 경고가 나올 수 있습니다. 사내에서 직접 만든 파일이라 서명이 없어서 그런 것이니, 이 파일이 맞다면 설치를 계속하면 됩니다.

### 4단계. (선택) Skill 등록

**보통은 건너뛰어도 됩니다.** 확장 파일에 답변 규칙이 이미 들어 있습니다. 5단계 확인에서 Claude가 근거 조문이나 시행일을 빠뜨리는 일이 잦을 때만 등록합니다.

1. Claude 데스크톱 앱에서 **설정 → 기능(Capabilities)**으로 들어갑니다.
2. **코드 실행 및 파일 생성(Code execution)**을 켭니다. Skill을 쓰려면 꼭 켜야 합니다.
3. 같은 화면의 **Skills**에서 **업로드(Upload skill)**를 누르고 `korean-tax-law-skill.zip`을 선택합니다.
   - zip 파일을 풀지 말고 그대로 올립니다.
4. 목록에 **korean-tax-law**가 보이고 켜져 있는지 확인합니다.

> 앱 버전에 따라 메뉴 이름이 조금 다를 수 있습니다. "데스크톱 앱 / Desktop app", "확장 프로그램 / Extensions", "기능 / Capabilities", "Skills"라는 단어를 찾으면 됩니다.

### 5단계. 잘 되는지 확인

새 대화를 열고 아래처럼 물어봅니다.

```
근로자 식대 비과세 한도가 얼마야? 근거 조문도 알려줘.
```

잘 설치됐다면 이렇게 됩니다.

- Claude가 답하기 전에 **"국가법령정보 조회" 도구를 사용해도 되는지** 물어봅니다. **허용**을 누릅니다. "항상 허용"을 고르면 다음부터는 묻지 않습니다.
- 답변에 **소득세법 제12조…** 같은 근거 조문과 **시행일**이 들어 있습니다.

## 4. 사용법

평소처럼 질문하면 됩니다. Claude가 알아서 필요한 법령과 조문을 조회합니다.

**질문 예시**

```
출산지원금 비과세 요건이 뭐야? 시행령까지 확인해서 알려줘.
```
```
부가가치세법 제26조 원문 보여줘.
```
```
소득세법 시행령에서 "자녀 보육" 들어간 조문 찾아줘.
```
```
1주택자 주택임대소득 비과세 기준을 법 조문 근거로 정리해줘.
```

**답변 형식**

답변은 아래 순서로 나옵니다.

1. 결론
2. 근거 조문 (예: 소득세법 제12조제3호러목)
3. 원문 발췌
4. 시행일
5. 주의사항

**더 정확하게 쓰는 팁**

- 법령명을 정확히 알면 같이 적어 주세요. 예: "소득세법 시행령 제17조의2"
- "시행령까지 확인해줘"라고 하면 세부 요건까지 조회합니다.
- 답변에 근거 조문이 없으면 "원문 조회해서 다시 답해줘"라고 요청하세요.

## 5. 무료 플랜 주의사항

- **사용량 한도가 낮습니다.** 법령 원문이 길어서 조회를 여러 번 하면 금방 한도에 걸립니다. 질문을 구체적으로 하면 조회 횟수가 줄어듭니다.
- 한도에 걸리면 시간이 지나 풀릴 때까지 기다려야 합니다.

## 6. 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| **"법제처 인증 실패: 사용자 정보 검증에 실패하였습니다"** | ① OC 값 오타: 설정 → 확장 프로그램 → 국가법령정보 조회에서 OC를 다시 입력합니다. ② OPEN API 사용 신청이 아직 승인되지 않았습니다. ③ 신청서에 적은 IP와 지금 PC의 공인 IP가 다릅니다. 집이나 카페, 휴대폰 테더링에서 쓰거나 사무실 IP가 바뀐 경우입니다. open.law.go.kr에서 IP를 추가하거나 수정합니다. |
| **"법제처 OC 값이 설정되지 않았습니다"** | 확장 설치 때 OC를 입력하지 않았습니다. 설정 → 확장 프로그램 → 국가법령정보 조회에서 입력합니다. |
| **Claude가 도구를 쓰지 않고 그냥 답함** | ① 확장이 꺼져 있는지 확인합니다. ② 질문에 "법령 원문 조회해서"라고 덧붙입니다. ③ 앱을 완전히 종료했다가 다시 켭니다. 작업 표시줄 오른쪽 아래 트레이 아이콘에서 종료해야 완전히 꺼집니다. ④ 그래도 자주 그러면 4단계 Skill을 추가로 등록합니다. |
| **확장 프로그램 메뉴가 없음** | 설정 → **데스크톱 앱** 안에 있습니다. 웹 브라우저(claude.ai)의 설정에는 없으니 데스크톱 앱인지 확인합니다. |
| **zip을 플러그인으로 올렸음** | 플러그인은 지웁니다. 도구는 `.mcpb`를 확장 프로그램으로 설치해야 동작합니다. |
| **"○○과 정확히 일치하는 법령이 없습니다"** | 법령명이 정확하지 않습니다. 오류 메시지에 나온 검색 후보 중 맞는 이름으로 다시 물어봅니다. |
| **확장 설치가 안 됨** | Claude 데스크톱 앱을 최신 버전으로 업데이트합니다. 웹(claude.ai)이 아니라 데스크톱 앱인지 확인합니다. |

## 7. 대표 PC 사용법

대표 PC는 확장 파일을 설치하지 않고, 이 폴더의 서버를 직접 연결해 둡니다.

**Claude 데스크톱 앱**
- 데스크톱 앱 설정 파일 `claude_desktop_config.json`의 `mcpServers`에 `korean-law`가 등록되어 있습니다. 이 폴더의 `src/mcp-server.js`를 실행하고, OC는 `.env`에서 읽습니다.
- 이 PC에 `.mcpb`를 또 설치하면 같은 도구가 두 번 생기니 설치하지 않습니다.
- 폴더 위치를 옮기면 설정 파일의 경로도 바꿔야 합니다.

**Claude Code**

이 폴더에서 Claude Code를 실행하면 바로 씁니다.

- 서버 등록: `.mcp.json`에 `korean-law` 서버가 등록되어 있습니다. Claude Code가 자동으로 켜고 끄므로 따로 실행할 필요가 없습니다.
- OC 값: 프로젝트 폴더의 `.env` 파일에 `LAW_OC=본인OC` 형식으로 적습니다. 이 파일은 다른 사람에게 주거나 깃에 올리지 않습니다.
- 답변 규칙: 서버에 들어 있고, `CLAUDE.md`에도 같은 내용이 있습니다.
- 처음 실행할 때 MCP 서버 사용 확인창이 뜨면 허용합니다. 연결 상태는 `/mcp`로 확인합니다.

## 8. 수정·재배포 (관리자용)

**폴더 구조**

```
src/law.js                     법제처 API 호출 (검색, 본문, 조문 추출)
src/mcp-server.js              MCP 서버 (도구 3개 + 답변 규칙 INSTRUCTIONS)
extension/manifest.json        데스크톱 확장 설정 (이름, 버전, OC 입력칸)
skill/korean-tax-law/SKILL.md  답변 규칙 (Skill)
scripts/build.mjs              배포 파일 빌드
dist/                          빌드 결과물 (직원에게 배포하는 파일)
```

**다시 빌드하기**

```
npm install
npm run build
```

`dist/korean-law.mcpb`와 `dist/korean-tax-law-skill.zip`이 새로 만들어집니다.

- 코드를 고쳤다면 `extension/manifest.json`의 `version`을 올린 뒤 빌드합니다. 예: `1.0.0` → `1.0.1`
- 직원들은 새 `.mcpb` 파일을 다시 설치하면 업데이트됩니다. OC는 다시 입력해야 할 수 있습니다.
- 답변 규칙을 고칠 때는 `src/mcp-server.js`의 `INSTRUCTIONS`와 `skill/korean-tax-law/SKILL.md`를 같이 고칩니다. Skill을 등록한 직원은 기존 Skill을 지우고 새 zip을 다시 올립니다.

**보안**

- 확장 파일과 Skill 파일에는 OC 값이 들어 있지 않습니다. OC는 각자 설치할 때 입력합니다.
- 대표 PC의 OC는 `.env`에만 있습니다. `.env`는 배포하지 않습니다.
